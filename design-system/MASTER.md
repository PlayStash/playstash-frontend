# PlayStash Design System

[DESIGN.md](../DESIGN.md) is the canonical visual system for the implemented “Steam, neu gedacht” redesign. Read its normative light/dark tokens and component guidance before creating UI. The live component sidecar is [.impeccable/design.json](../.impeccable/design.json).

Use Inter, semantic `--color-ps-*` theme properties, flat navy/blue-grey surfaces, ice-blue actions, and small control corners. Theme selection, localization, and web/desktop behavior remain intact.

Page notes in [auth.md](pages/auth.md) and [library.md](pages/library.md) describe composition; they do not override the canonical system. Former purple/glass, oversized-radius, and unrelated font specifications are superseded.
