# PlayStash Design System

The canonical specification is [DESIGN.md](../../DESIGN.md), extracted from the implemented “Steam, neu gedacht” interface. The machine-readable extension is [.impeccable/design.json](../../.impeccable/design.json).

Use those sources for actual light/dark colors, Inter typography, compact shapes, component states, depth, and motion. The former generated purple/rose palette, Fredoka/Nunito pairing, and social-media landing-page pattern do not describe PlayStash and are superseded. Page notes are subordinate to the root visual system.
